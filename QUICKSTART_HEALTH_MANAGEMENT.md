# 🚀 Quick Start Guide - Health Management Admin Module

## 5-Minute Setup

### **Step 1: Log In (1 minute)**
```
URL: http://localhost/make_simple/admin-dashboard.php
Username: Your admin username
Password: Your admin password
```

### **Step 2: Navigate to Health Offers (1 minute)**
1. Look for "💊 Health Offers" in Quick Actions
2. Or use direct URL: `http://localhost/make_simple/admin-health-offers-manage.php`

### **Step 3: Create Your First Offer (2 minutes)**
```
1. Click "➕ Add New Offer" tab
2. Fill in:
   - Title: "Your Offer Name"
   - Description: "Brief description"
   - Original Price: 5000
   - Discounted Price: 3500
   - Dates: Select start and end dates
3. Upload image (900×220px recommended)
4. Check "Active" box
5. Click "➕ Create Offer"
```

### **Step 4: Verify on Dashboard (1 minute)**
```
1. Log out or open new browser tab
2. Go to: http://localhost/make_simple/dashboard.php
3. Log in as patient
4. Scroll to "My Health Offers"
5. Your new offer should appear!
```

## 📸 Upload Doctor Photos

### **Quick Steps**
1. Admin Dashboard → "👨‍⚕️ Doctor Profile Photos"
2. Select doctor from dropdown
3. Upload photo (JPG/PNG/WEBP, max 5MB)
4. Click "📤 Upload Photo"
5. Done! Photo appears throughout the system

## 📞 Need Help?

### **Common Tasks**

**Q: How do I make an offer visible?**
A: Check the "Active" checkbox when creating/editing

**Q: When will the offer stop showing?**
A: On the "Validity End" date

**Q: Can I edit an offer after creating it?**
A: Yes! Go to "Manage Offers" tab and click Edit

**Q: What image size should I use?**
A: 900×220px for health offers, square/portrait for doctor photos

**Q: How big can files be?**
A: Maximum 5MB for any image
